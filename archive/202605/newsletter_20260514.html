AI 리서치/검색 초급~중급

Perplexity AI — 출처가 자동으로 따라오는 AI 리서치 도구

검색하면 답변과 함께 원문 출처 링크가 자동으로 붙습니다

이번 주 선정 이유 : 2026년 5월 Personal Computer Mac 전면 공개 + Deep Research 정확도 업계 최고 수준 달성 — 기술 동향 리서치와 규격 추적에 즉시 활용 가능
핵심 요약

Perplexity AI는 실시간 웹 검색과 생성형 AI를 결합한 리서치 도구입니다. 질문하면 웹을 탐색한 뒤 출처 링크와 함께 정리된 답변을 제공합니다. 기존 검색 엔진처럼 링크 목록을 나열하지 않고, 질문에 대한 직접적인 답변을 구성해줍니다.

최근 19개 AI 모델을 조합해 복잡한 업무를 자동 수행하는 'Computer' 에이전트 기능을 Mac에 전면 공개했습니다. Deep Research 기능은 SimpleQA 벤치마크에서 93.9% 팩트 정확도를 기록하며 업계 최고 수준을 달성했습니다 (출처 : Perplexity Research 2026-05).

무료 플랜으로 시작할 수 있으며, Enterprise 플랜은 SSO, 감사 로그, 데이터 비학습 보장 등 기업 관리 기능을 갖추고 있습니다. 월 10억 건 이상의 질의를 처리하며 빠르게 성장 중입니다 (출처 : Perplexity 공식 발표 2026-03).
KEY CAPABILITIES
출처 인용 답변 — 모든 응답에 원문 출처 링크 자동 첨부, 주장마다 근거 확인 가능
Deep Research — 복잡한 주제를 다단계로 자동 조사, SimpleQA 93.9% 정확도 (Perplexity Research 2026-05)
Computer (에이전틱 작업) — 19개 모델 조합으로 문서 분석, 보고서 작성, 데이터 정리를 자동 수행
Spaces (팀 협업) — 팀 단위 공유 리서치 공간, 커스텀 스킬로 반복 업무 표준화 가능
멀티소스 집중 검색 — 학술 논문, 뉴스, 유튜브 등 소스 유형별 Focus 모드로 정밀 검색
이미지 출처 : TechCrunch
USE CASES — 제조/AX 실무 시나리오
1. 기술 동향 리서치 (개발/품질/생산기술 등) — OEM 신규 기술 요구사항 파악 시 관련 논문, 보도, 표준 문서를 출처와 함께 수 분 내 요약
 
2. 경쟁사/공급망 정보 수집 (구매/영업/기획 등) — 부품 소재별 글로벌 공급업체 동향, 원자재 가격 추이를 출처 기반으로 정리
 
3. 보고서/제안서 초안 작성 (전 부서) — 특정 주제의 최신 레퍼런스를 검색해 근거 자료와 함께 초안 구조를 제안받을 수 있음
 
4. 규격/인증 변경 추적 (품질/설계/생산기술 등) — 자동차부품 관련 국제 규격(IATF, ISO 등) 개정 동향을 실시간 웹 검색으로 파악

GETTING STARTED — 5단계 온보딩
1
perplexity.ai 접속, 무료 계정 생성
Google 또는 이메일로 가입. 별도 설치 없이 웹 브라우저에서 바로 사용 가능
2
첫 질문 입력 — 구체적으로 질문하기
예시 : "자동차 내장재 친환경 소재 트렌드 2026" — 구체적일수록 정확한 답변을 얻을 수 있음
3
Focus 모드 활용 — 소스 유형 선택
'학술', '뉴스', '전체' 등 소스 유형을 선택해 검색 범위 조절. 기술 규격 관련은 '학술' 모드 추천
4
실전 팁 — 한국어 검색 정확도 높이기
핵심 키워드는 영어로 검색한 뒤 "한국어로 요약해줘"라고 후속 질문하면 정확도와 가독성 모두 향상. 한국어 단독 검색보다 영문 키워드 후 번역 요청이 더 효과적
5
Spaces로 팀 리서치 공간 만들기
프로젝트별 리서치 공간을 생성해 검색 결과와 대화 이력을 팀원과 공유 가능. 커스텀 스킬 설정으로 반복 리서치를 표준화할 수 있음
PITFALLS
A) 도구 자체 한계
— 무료 플랜은 Pro Search 하루 5회 제한. Deep Research는 Pro($20/월) 이상에서만 사용 가능
— 한국어 검색 품질이 영어 대비 낮을 수 있음. 전문 용어가 많은 기술 리서치는 영어 검색 권장
— Computer 에이전트 기능은 Max($200/월) 전용이며, 현재 웹과 Mac에서만 사용 가능
B) 사내 도입 시 주의
— 무료/Pro 플랜에서는 질의 내용이 모델 개선에 활용될 수 있음. 기밀 문서 입력 시 Enterprise 플랜(데이터 비학습 보장) 검토 필요
— Enterprise 플랜은 SSO, 감사 로그 제공. SOC 2 Type II 인증 여부는 도입 전 확인 필요
— 출처 링크가 있어도 100% 정확하지는 않음. 원문을 클릭해 직접 확인하는 습관이 중요
