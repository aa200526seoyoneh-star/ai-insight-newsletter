AI 어시스턴트 전 직군

ChatGPT — GPT-5.5 + Excel 통합 + 워크스페이스 에이전트

자연어 한 줄로 스프레드시트 분석부터 팀 업무 자동화까지

이미지 출처 : OpenAI
이번 주 선정 이유 : 4월 GPT-5.5 출시(MMLU 92.4%) + 5월 Excel/Sheets 통합 정식 오픈 + 워크스페이스 에이전트로 팀 업무 자동화 가능
핵심 요약

ChatGPT는 OpenAI가 만든 대화형 AI 어시스턴트로, 텍스트 생성 / 데이터 분석 / 코드 작성 / 웹 리서치를 하나의 인터페이스에서 처리합니다. 2026년 4월 GPT-5.5 모델 탑재로 100만 토큰 컨텍스트와 에이전틱 실행 능력이 대폭 강화됐습니다.

최근 업데이트 : 5월 Excel/Google Sheets 공식 통합(GPT-5.5 기반), 워크스페이스 에이전트(팀 단위 자동화, Slack 연동), Codex 역할별 플러그인(데이터 분석/제작 등) 추가.

사내 도입 경로 : 무료 계정으로 기본 기능 체험 가능. 업무 본격 활용은 Plus($20/월)부터. 팀 단위 보안/감사 로그가 필요하면 Business($20~25/인/월)나 Enterprise(맞춤 견적) 검토.
Key Capabilities
1. GPT-5.5 추론 엔진 — MMLU 92.4%, 100만 토큰 장문맥, 에이전틱 코딩 82.7% (출처 : OpenAI 2026-04-23)
2. Excel/Sheets 네이티브 통합 — 자연어로 스프레드시트 모델 생성, 수식 감사, 시나리오 분석 지원
3. 워크스페이스 에이전트 — 클라우드 상시 가동, Slack/Salesforce 연동, MCP 개방형 표준 지원
4. Deep Research — 다단계 웹 리서치 자동 수행, 출처 포함 보고서 생성 (Plus 이상)
5. Codex + 역할 플러그인 — 코드 생성/실행, 데이터분석/제작/영업 등 6개 역할별 특화 모드
이미지 출처 : OpenAI
Use Cases — 제조/AX 실무 시나리오
1. 품질 데이터 분석 자동화 (품질/생산기술/개발 등)
Excel 통합으로 검사 성적서, 공정 데이터 등의 이상치 탐지와 트렌드 분석을 자연어 한 줄로 실행. 기존 수작업 대비 분석 준비 시간을 줄일 수 있음.
2. 기술 문서 번역/요약 (전 부서)
해외 OEM 기술 사양서, 규격서, 특허 문서를 100만 토큰 장문맥으로 통째로 업로드해 한국어 핵심 요약 추출. 원문 참조 셀까지 연동 가능.
3. 공급망/시장 동향 리서치 (구매/SCM/기획 등)
Deep Research로 원자재 가격 동향, 경쟁사 동향, 규제 변경 사항을 자동 조사하고 출처 포함 보고서를 생성. 주간/월간 브리핑 자료 작성에 활용 가능.
4. 보고서/회의록 자동 정리 (전 부서)
워크스페이스 에이전트가 회의 내용 요약, 액션 아이템 추출, Slack 채널 공유까지 자동 처리. 일일/주간 보고서 초안 작성 보조에도 활용 가능.

Getting Started — 5단계 온보딩
1
무료 계정 생성
chatgpt.com 접속 후 회사 이메일 또는 개인 Google 계정으로 가입. 별도 설치 없이 웹 브라우저에서 바로 사용 가능.
2
업무용 프롬프트 첫 실행
"이 엑셀 데이터에서 불량률 상위 5개 항목을 뽑아줘"처럼 업무 맥락을 구체적으로 설명하면 정확도가 올라감.
3
Excel/Sheets 애드인 체험
Excel 메뉴 > ChatGPT 애드인 설치 후, 워크북에서 직접 자연어로 데이터 분석 요청. Sheets는 확장 프로그램에서 설치.
4
실전 팁 : 역할 지정 + 출력 형식 고정
공식 문서에 없는 팁 "너는 자동차 부품 품질 엔지니어야. 결과는 표 형태로, 수치에는 단위를 붙여줘"처럼 역할과 출력 형식을 첫 메시지에 고정하면 후속 대화의 정확도와 일관성이 눈에 띄게 올라감.
5
팀 도입 시 Business 플랜 검토
Business 플랜($20~25/인/월)은 대화 데이터 학습 차단이 기본 적용되고, 관리자 콘솔에서 사용량 모니터링과 접속 제어가 가능. 2인 이상이면 도입 가능.
Pitfalls
A) 도구 자체 한계
무료 플랜 제약 — GPT-5.3만 사용 가능, 5시간당 메시지 10회 제한, 파일 업로드 하루 3건(512MB). 업무용으로는 부족.
한국어 표/문서 인식 — 복잡한 한국어 표 구조(병합 셀, 세로 헤더)는 영문 대비 인식 정확도가 떨어짐. 중요 수치는 원본 대조 필수.
할루시네이션 — 그럴듯하지만 틀린 답변 가능성 상존. 특히 정량 수치/규격 번호/법규 인용은 반드시 1차 출처에서 검증해야 함.
B) 사내 도입 시 주의
데이터 학습 정책 — Free/Plus/Go 플랜은 대화 내용이 모델 학습에 활용될 수 있음. 기밀 데이터 입력 전 반드시 Business/Enterprise 플랜으로 전환하거나 학습 차단 설정 확인.
보안 거버넌스 — Enterprise 미만 플랜은 SSO/감사 로그/데이터 보존 정책 미지원. 팀 단위 도입 시 정보보안팀과 사전 협의 필요.
API 비용 관리 — GPT-5.5 API는 입력 $5/100만 토큰, 출력 $30/100만 토큰 (출처 : OpenAI 2026-04-23). 자동화 파이프라인 구축 시 토큰 사용량 모니터링 필수.
