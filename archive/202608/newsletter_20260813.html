AI 도구 활용 입문

Perplexity AI — AI 네이티브 검색 엔진에서 자기학습 에이전트 플랫폼으로

이번 주 선정 이유 : 7월 Brain(자기개선 메모리) 정식 출시 + Computer 에이전트 기업용 확장으로 AI 검색 도구의 패러다임이 바뀌고 있다. Perplexity AI는 질문에 대해 웹을 실시간 검색한 뒤, 출처를 인라인으로 달아 답변하는 AI 네이티브 검색 엔진이다. 2024년 출시 이후 빠르게 성장해 2026년 현재 월간 7.8억 건 이상의 쿼리를 처리하며, ARR $4.5억을 달성했다. 2026년 2월 광고를 전면 폐지해 순수 구독 모델로 전환한 뒤 매출이 오히려 50% 증가한 이례적 사례로도 주목받았다. 핵심 변화는 두 가지다. 첫째, 19개 프론티어 모델(GPT-5.2, Claude Opus 4.6, Gemini 3.1 Pro, Grok 4 등)을 자동 배정하는 에이전트 플랫폼 Computer를 출시해 단순 검색을 넘어 멀티스텝 업무 자동화로 확장했다. 둘째, 7월 Brain 메모리 시스템을 도입해 에이전트가 과거 작업 이력을 축적하고 야간에 자동 학습하는 구조를 갖췄다. 맥락이 필요한 반복 작업에서 정확도 25% 향상, 비용 13% 절감이 보고되었다.

핵심 요약

Perplexity AI의 Brain 자기개선 메모리가 검색 에이전트를 업무 파트너로 바꾸고 있다

서연이화 관점
1차 부품사 실무에서 Perplexity의 가치는 '출처가 달린 빠른 리서치'에 있다. OEM 사양 변경, 신소재 동향, 해외 규격 개정처럼 구매/품질/설계 등 여러 부서가 산발적으로 수행하는 외부 정보 탐색을 한 곳에서 출처와 함께 정리할 수 있다. Brain 메모리가 반복 업무 패턴을 학습하면 매주 되풀이되는 동종 리서치의 준비 시간이 줄어드는 효과도 기대된다.
KEY CAPABILITIES
1
출처 인라인 인용 검색
모든 답변에 출처 링크를 문장 단위로 표기해 사실 확인이 즉시 가능하다. 광고 없이 순수 정보만 제공하므로 검색 결과 신뢰도가 높다는 평가를 받고 있다
2
19개 모델 자동 배정(Computer)
GPT-5.2, Claude Opus 4.6, Gemini 3.1 Pro 등 프론티어 모델을 작업 성격에 따라 자동 선택하고 병렬 실행한다. 사용자는 모델을 고를 필요 없이 목표만 지시하면 된다
3
Brain 자기개선 메모리
에이전트가 수행한 작업 이력을 컨텍스트 그래프로 축적하고, 야간 자동 학습으로 다음 세션에 반영한다. 사용자가 직접 기억을 작성할 필요 없이 시스템이 자동 추론한다
4
Model Council 멀티모델 비교
하나의 질문을 여러 모델에 동시 전송해 답변을 나란히 비교할 수 있다. 2026년 2월 출시, Pro 이상 구독자 사용 가능
5
Spaces 팀 지식 허브
검색 결과와 문서를 주제별 컬렉션으로 정리해 팀원과 공유한다. Enterprise에서는 Slack, Snowflake, Salesforce 등 400개 이상 앱 커넥터와 연동 가능
USE CASES
1
해외 공급업체 소싱 리서치
구매/영업/품질 등 여러 부서가 수행하는 해외 소재 공급업체 조사에서 Pro Search로 최신 가격 동향과 인증 현황을 출처 포함 보고서로 한 번에 정리할 수 있다
2
OEM 사양/규격 변경 추적
설계/생산기술/품질 등에서 참조하는 완성차 OEM 사양 변경이나 IATF, ISO 등 국제 규격 개정 내용을 실시간 검색하고 핵심만 요약해 팀에 공유할 수 있다
3
자동차 내장재 기술 문헌 허브
내장재/시트/표면처리 등 제조 공정과 관련된 신소재 논문, 특허, 업계 보고서를 Spaces에 축적해 팀 공유 기술 지식 베이스로 활용할 수 있다
4
시장 동향/경쟁사 분석 자동화
부서를 가리지 않고 반복되는 경쟁사 동향, 산업 전시회 트렌드, 정부 지원사업 정보 리서치를 Computer 에이전트에 위임해 초안을 자동 생성할 수 있다

GETTING STARTED
1
1단계 — 계정 생성과 첫 검색
perplexity.ai 접속 후 Google 또는 이메일로 가입한다. 무료 계정으로도 기본 검색은 무제한이고, Pro Search는 하루 5회 사용 가능하다
2
2단계 — Pro Search로 심층 리서치 체험
검색창 아래 'Pro' 토글을 켜고 업무 관련 질문을 던져본다. 일반 검색 대비 출처 수와 분석 깊이가 눈에 띄게 다르다
3
3단계 — Spaces에 첫 컬렉션 만들기
좌측 메뉴 Spaces에서 'OEM 사양 동향' 같은 주제 컬렉션을 하나 만들고, 유용한 검색 결과를 저장해 팀 레퍼런스로 활용한다
4
4단계 — 한국어 프롬프트 최적화(실전 팁)
한국어 질문 시 '한국어로 답변해 줘'를 명시하면 출처 요약도 한국어로 출력된다. 영문 원문 인용이 필요하면 '원문 인용 포함'을 추가한다. 공식 문서에 없는 현장 팁이다
5
5단계 — Computer 에이전트 첫 실행
Pro 이상 구독 후 Computer 탭에서 '이번 달 자동차 부품 산업 AI 도입 동향 보고서 초안 작성'처럼 멀티스텝 목표를 지시해본다. 에이전트가 하위 작업을 자동 분할해 실행한다
PITFALLS
⚠ 검색 범위 제한 — 공개 웹만 탐색
Perplexity는 공개 웹 페이지만 검색한다. 사내 ERP, 폐쇄망 문서, 유료 DB(논문 전문 등)는 탐색 대상이 아니므로 내부 데이터 분석 도구와 혼동하지 말아야 한다
⚠ Pro Search 일일 한도 — 무료 5회
무료 계정의 Pro Search는 하루 5회로 제한된다. Pro 구독 시 무제한이지만 피크 시간대 응답 지연이 발생할 수 있다. 2월 이후 한도 정책이 예고 없이 변경된 전례가 있으므로 유의
⚠ 개인 플랜 데이터 수집 기본 활성화
Free/Pro/Max 개인 플랜은 AI 학습용 데이터 수집이 기본 활성화 상태다. 설정에서 'AI data retention'을 수동으로 꺼야 한다. Enterprise 플랜은 학습 제외가 기본값
⚠ Enterprise Max 비용 — 석당 월 $325
Enterprise Max는 석당 월 $325로 ChatGPT Team($30) 대비 10배 이상이다. 전사 도입 전 소규모 파일럿으로 ROI를 먼저 측정하는 접근이 현실적
⚠ 추적 소프트웨어 집단소송 진행 중
2026년 4월 Perplexity 앱에 비공개 추적 소프트웨어가 포함되었다는 집단소송이 제기되었다. 소송 진행 중이므로 민감 정보 직접 입력은 자제하고 Enterprise 플랜의 데이터 보호 조건을 확인할 필요가 있다
